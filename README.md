## 机房线路全面解析

VMISS最大的优势就是机房多、线路全。我挑几个比较有代表性的说说。

### 美国洛杉矶三网优化（US.LA.TRI系列）

这个系列算是VMISS的招牌产品之一。什么叫三网优化？就是针对电信、联通、移动三家运营商，分别配置了最优的回程线路。

电信用户走CN2 GIA，联通用户走AS9929，移动用户走CMIN2。听起来可能有点懵，简单说就是，不管你用的哪家宽带，它都能给你找到最快的路回国。不用再担心绕道半个地球才能访问服务器。

带宽从200Mbps到500Mbps不等，流量也给得挺足。最低配的套餐1核1G内存10G硬盘，500G月流量，折后大概就是25人民币左右一个月。这个价格拿这个配置和线路，真的没啥好挑剔的。

### 香港CMI线路（HK.BGP系列）

香港机房有好几个系列，其中CMI线路的性价比最高。CMI就是中国移动的国际线路，主要适合移动宽带用户。如果你是电信或者联通，可能会走NTT或者其他国际线路绕一圈，延迟会高一些。

但是架不住便宜啊。最低配的套餐年付才30加元，折合人民币差不多150块钱一年。平均下来一个月12.5元，而且是香港机房。虽然不是三网直连，但对移动用户来说体验还是不错的。

而且香港机房还有个好处，就是不用备案。你懂的，有些业务不方便备案，或者嫌备案麻烦，香港机房就是最好的选择。延迟也比美国低得多，Ping值基本在50ms以内。

### 日本东京三网优化（JP.TKY.TRI系列）

这是VMISS最新上线的产品系列，也是他们花了血本搞的。电信走CN2，联通和移动直连，而且还加了智能路由功能。

什么是智能路由？就是系统会根据你的数据包大小和类型，自动选择最优的路径。小包数据比如网页浏览、SSH连接这些，走CN2保证低延迟；大包数据比如下载、看视频，走AS4134保证带宽够用。

这样的好处是什么呢？就是既保证了速度，又不会浪费昂贵的CN2流量。毕竟CN2 GIA的流量成本是很高的，商家也得考虑成本控制。

日本机房的延迟普遍比美国低，大概在60-80ms左右。对于需要低延迟的应用，比如游戏服务器、实时通讯之类的，日本机房是个不错的选择。

### 韩国首尔CN2线路

韩国机房的特点是延迟更低，基本能控制在40-60ms。而且韩国的网络基础设施很好，国际出口带宽充足，不容易被挤爆。

不过韩国机房的带宽相对小一些，一般是100Mbps。对于大流量应用可能不太够用，但日常使用、建站、跑跑脚本什么的完全没问题。
